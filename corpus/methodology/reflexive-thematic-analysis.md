# Reflexive Thematic Analysis

## Definition and scope

Reflexive thematic analysis (TA) is a qualitative analytic approach for identifying,
analyzing, and reporting patterns (themes) in data with explicit researcher reflexivity.
It is **not** a standalone method of data collection.

**Not the same as:** codebook TA with fixed codes, content analysis, or grounded theory.

## Typical research questions

Experience, meaning, and pattern across a dataset where flexible interpretive coding fits.

## Data collection

Often interviews or focus groups; fit depends on RQ, not the TA label alone.

## Analysis procedure

Familiarization → coding → theme development → review → definition → write-up.
Reflexivity about how researcher subjectivity shapes theme construction.

## Rigor criteria

Coherent analytic narrative, defensible theme boundaries, sufficient data excerpts,
transparent reflexivity — not inter-rater reliability as default gold standard.

## Common misuses

- Labeling as "thematic analysis" while only descriptive summarizing
- Confusing **themes** with **questions** or **codes**
- Claiming GT because of "emergent themes"
- Omitting reflexivity in reflexive TA

## Reviewer questions checklist

- Are themes analytic rather than purely descriptive?
- Is the distinction between codes and themes clear?
- Does the methods section match Braun & Clarke reflexive TA (if claimed)?

## Distinction from related methods

| Related method | Key difference |
|----------------|----------------|
| Codebook TA | Pre-defined codes; less reflexive theme generation |
| Grounded theory | Theory generation focus; different procedural logic |
